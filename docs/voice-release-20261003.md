## 限制與下一步

技術驗收不等於真人驗聽，也不能保證全部多音字正確。先試聽交付的六句男聲，確認清晰度與節奏；5 句未決項及部分長句的人名、古音仍需教材／聽辨核對。正式部署需另行確認，部署後再核對線上版本與音檔雜湊。
